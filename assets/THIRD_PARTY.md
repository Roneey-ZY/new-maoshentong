# Local design assets

- GSAP and ScrollTrigger 3.14.2: official npm `gsap` tarball, checked against the npm SHA512 integrity before extracting the two distribution files. Original distribution headers are preserved. Publication URL, integrity and extracted SHA256 values are in `vendor/gsap-release.json`; upstream README and its standard no-charge license link are in `vendor/GSAP-README.md`. No runtime CDN loading.
- Funnel Display, weight 500: official Google Fonts `fonts.gstatic.com/s/funneldisplay/v3/B50bF7FGv37QNVWgE0ga--4PbZSRJXrOHcLHLoAYqGPXWA.ttf`. SIL Open Font License is preserved in `fonts/OFL.txt`. The small display face is embedded locally; Chinese text uses the visitor's system fonts. No Google Fonts runtime request.
- TradeCheck wordmark, document rows and route: original HTML/CSS, representing the project's own document types. No stock photographs, third-party product screenshots or invented customer logos.

Taste and GSAP skills informed design and implementation. Their own scripts/assets have not been modified.
